### Running locally
1. Install ruby (Windows: `winget install RubyInstallerTeam.RubyWithDevKit.3.2`)
2. Install bundler (`gem install bundler`)
3. Install dependencies (`bundle install`)
4. Run (`bundle exec jekyll serve`)
5. From your phone on the same network, visit `http://<your-PC-IP>:4000/`
6. If it doesn't load, allow inbound access to port `4000` in Windows Firewall
